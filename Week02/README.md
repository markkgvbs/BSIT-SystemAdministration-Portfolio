Week 2 Portfolio Project – Enterprise Infrastructure Planning



Project Overview



This project involved preparing a complete IT Infrastructure Plan for TechLine Solutions, a fictional 20-employee software startup with no existing computers, network, or infrastructure. Acting as the Junior System Administrator, I designed the hardware, software, and network setup from scratch, along with a network topology diagram, and documented everything in a professional report.



Learning Objectives



\* Analyze the IT requirements of a small business based on its departments and headcount.

\* Prepare professional hardware, software, and network inventories.

\* Design an enterprise network topology using proper networking symbols.

\* Research real-world System Administration roles and how they collaborate.

\* Communicate infrastructure planning decisions in professional technical documentation.



Company Scenario



TechLine Solutions is a newly established software development startup with 20 employees across IT, HR, Finance, and Sales departments. The company currently has no computers, server, network, or internet infrastructure, so the entire IT setup needed to be planned from the ground up.



Hardware Inventory Summary



Key hardware includes desktop computers for HR, Finance, and Sales, laptops for the IT team, one server, a NAS for backups, two switches, two wireless access points, a shared printer, and monitors for all 20 employees. See the full inventory with justifications in \[EnterpriseInfrastructurePlan.pdf](./EnterpriseInfrastructurePlan.pdf).



Software Inventory Summary



Core software includes Windows 11 Pro for workstations, Ubuntu Server for the company server, Microsoft Office for daily productivity, and IT/development tools such as Git, GitHub Desktop, VS Code, and VirtualBox. Security is covered by Microsoft Defender, with AnyDesk for remote support. Full details and justifications are in the PDF report.

Challenges Encountered



The most challenging part of this project was designing the network diagram in Draw.io, since it required learning how to use proper networking symbols and organize a clean, readable layout showing the flow from the internet down to each department. Deciding on realistic hardware quantities for a 20-person company also required careful reasoning rather than guesswork, to avoid over- or under-provisioning equipment.



Reflection



This project shifted my understanding of System Administration from just fixing problems to also planning infrastructure before it exists. Full reflection is available in \[EnterpriseInfrastructurePlan.pdf](./EnterpriseInfrastructurePlan.pdf).
